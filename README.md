# 📚 Library Management System

## 📖 Overview
This project was developed during my internship using **PHP**, **MySQL (phpMyAdmin)**, and **SQL**.

The application is a library management system that allows administrators to manage books efficiently. 
It includes authentication, database operations, and advanced sorting features.

---

## 🚀 Features

- 🔐 Secure admin login using **PHP Sessions** and **Cookies**
- 📚 Manage the library database
- ➕ Add new books
- ✏️ Update existing book information
- ❌ Delete books
- 👀 View all books
- 🔍 Sort books by:
  - Author name (Ascending / Descending)
  - Book title (Ascending / Descending)
  - Publication year (Ascending / Descending)

---

## 🗄️ Database

The application uses a **MySQL** database managed through **phpMyAdmin**.

The database stores information about books, including:
- Book title
- Author
- Publication year


---

## 🔑 Authentication

The admin panel is protected through:
- PHP Sessions
- Cookies
- Login authentication

Only authenticated administrators can access the management interface.

---

## 📂 CRUD Operations

The application supports full CRUD functionality:

- **Create** - Add new books
- **Read** - Display all books
- **Update** - Edit existing books
- **Delete** - Remove books
